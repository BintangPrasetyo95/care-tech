I2S AUDIO DAC

Uji speaker 3W pada amplifier MAX98357A robot. ESP32 akan memainkan melodi arpeggio 6-nada CareTech yang jernih:

Pin: BCLK(26), LRC(25), DIN(22), VIN(5V)
I2S MEMS MIC

ESP32 akan merekam suaramu selama 2 detik dari INMP441, mengirimkan audio ke browser via serial, dan memutarnya balik di speaker robot (MAX98357A) DAN speaker laptop:

Pin: SD(32), WS(33), SCK(14), VDD(3.3V)
📋 Peta Pinout Lengkap ESP32 + MAX98357A + INMP441
1. MAX98357A Speaker DAC (Papan Ungu):
• VIN → ESP32 VIN (5V USB)
• GND → ESP32 GND
• BCLK → ESP32 GPIO 26
• LRC → ESP32 GPIO 25
• DIN → ESP32 GPIO 22
• GAIN & SD → Biarkan terbuka (Floating)
• Terminal → Speaker 4Ω/8Ω 3W
2. INMP441 Mikrofon MEMS (Papan Bundar):
• VDD → ESP32 3V3 (3.3V WAJIB! JANGAN 5V)
• GND → ESP32 GND
• SD → ESP32 GPIO 32
• WS → ESP32 GPIO 33
• SCK → ESP32 GPIO 14
• L/R → ESP32 GND
